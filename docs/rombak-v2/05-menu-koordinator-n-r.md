# 05 — Menu Koordinator Staf N–R

Tidak ada Claude Doc tersendiri; keputusan berasal dari sesi perancangan 26 Nov 2026 dan mockup kanvas halaman **koor-r** (KR-1-Tim … KR-7-Progres).

Sama dengan Koordinator A–M (doc 04) untuk tab Jurnal, Progres, Akun, Verifikasi, Delegasi, Profil staf, dan Kartu Penilaian. Bedanya: **tidak ada Jadwal kegiatan SKUO dan Manage tim**; gantinya **Set Tugas** dan **Atur Tugas Staf**.

## Segmen Tim pada tab Tugas

| Layar | Isi |
| --- | --- |
| KR-1 Tim | Tiga angka (Perlu diperiksa · Terlambat · Belum ada aktivitas hari ini) + pintasan ke layar di bawah |
| KR-2 Verifikasi | Daftar tugas staf. Setujui, Tolak (alasan wajib), **Setujui semua yang tepat waktu** (item terlambat tidak ikut) |
| KR-3 Set Tugas | Daftar Set Tugas unit (seperti folder), mis. "Keamanan shift pagi", "Kebersihan harian". Buat baru, salin |
| KR-4 Ubah set tugas | Isi satu set: judul tugas, frekuensi (harian/pekanan + hari), jam tenggat, link bukti wajib atau tidak |
| KR-5 Atur Tugas Staf | Grid per pekan: staf × Set Tugas. Satu set bisa dipasang ke banyak staf sekaligus (penting untuk 15 staf Keamanan) |
| KR-6 Usulan | Usulan tugas rutin dari staf; koordinator menerima dan **boleh memasukkannya ke Set Tugas mana pun**, atau menolak |
| KR-7 Progres | K1 koordinator = rata-rata K1 staf unitnya, daftar K1 per staf |

## Keputusan

| Hal | Keputusan |
| --- | --- |
| Istilah | **"Set Tugas"** (bukan template) dan **"Atur Tugas Staf"** (bukan pemasangan) |
| Sifat Set Tugas | Kumpulan tugas rutin bernama; tidak harus terkait shift. Tidak ada jam shift di set |
| Periode Atur Tugas Staf | Per pekan |
| Pekan berikutnya | **Otomatis berlanjut** (auto carry-over): bila koordinator tidak mengubah apa pun, susunan pekan lalu berlaku lagi |
| Perubahan set atau susunan | **Berlaku mulai besok**; tugas hari ini yang sudah terbit tidak berubah |
| Tugas lewat tengah malam | Pengaturan per Set Tugas, **hanya Admin** |
| Usulan staf | Koordinator bisa memindahkan usulan ke set lain |
| Pemeriksaan | Persetujuan massal untuk item tepat waktu; item terlambat diperiksa satu per satu |
| K1 koordinator | Rata-rata K1 staf unitnya (sama dengan A–M) |
